Imperative → HOW to do something
Declarative → WHAT you want
🔹 1. Imperative Programming

Imperative code describes step-by-step instructions for achieving a result.

You explicitly control:

loops
variables
state changes
execution steps
✅ Example (Imperative)
List<int> numbers = [1,2,3,4,5];

List<int> evens = new();

foreach (var n in numbers)
{
    if (n % 2 == 0)
    {
        evens.Add(n);
    }
}
🔥 What are you telling the computer?
1. Create list
2. Iterate manually
3. Check condition
4. Add items manually

You describe:

HOW to perform operation
🔹 2. Declarative Programming

Declarative code describes the desired result without specifying detailed execution steps.

✅ Example (Declarative)
var evens = numbers.Where(x => x % 2 == 0);
🔥 What are you telling the computer?
“I want even numbers.”

NOT:

“how to iterate and store them”
🔹 Key Mental Difference
Imperative
Focus on CONTROL FLOW
Declarative
Focus on RESULT
🔹 Real-World Analogy
Imperative

Like giving GPS turn-by-turn instructions:

Turn right
Go 200m
Turn left
Declarative

Like saying:

Take me to Cairo

System decides HOW.

🔹 SQL is Declarative
SELECT * FROM Employees WHERE Salary > 5000

You say:

what data you want

NOT:

how database engine scans memory
🔹 LINQ is Declarative
Declarative LINQ
var result = employees
    .Where(x => x.Salary > 5000)
    .OrderBy(x => x.Name);

You describe:

desired transformation
🔹 Imperative Equivalent
List<Employee> result = new();

foreach (var emp in employees)
{
    if (emp.Salary > 5000)
    {
        result.Add(emp);
    }
}

result.Sort(...);
🔥 Declarative code is usually:
shorter
higher-level
more expressive
🔹 Imperative Style Characteristics
✔ Explicit state manipulation
i++;
✔ Loops
for / while / foreach
✔ Variable mutation
✔ Manual control
🔹 Declarative Style Characteristics
✔ Expressions
✔ Transformations
✔ Queries
✔ Reduced mutation
✔ Higher abstraction
🔹 Important Truth

Declarative code still becomes imperative internally.

Example:

numbers.Where(...)

Internally:

some hidden loops still exist

You just don’t manage them yourself.

⚡ Final Comprehensive Summary (your style)

Imperative programming focuses on describing how a task should be performed through explicit control flow, loops, state changes, and step-by-step instructions, while declarative programming focuses on describing what result is desired without specifying the exact execution process. Declarative code usually operates at a higher abstraction level, emphasizing expressions, transformations, and intent rather than manual control logic. LINQ and SQL are common declarative styles, whereas loops and mutable state manipulation represent imperative style.
